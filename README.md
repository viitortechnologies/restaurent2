# Happy Food - Authentic Hyderabad Cuisine

A modern, responsive website for "Happy Food" - an authentic Hyderabad-based Indian restaurant. This website showcases the rich culinary heritage of Hyderabad with beautiful imagery, interactive features, and a user-friendly design.

## 🌟 Features

### Design & User Experience
- **Modern & Responsive Design**: Fully responsive layout that works on all devices
- **Hyderabad Theme**: Beautiful imagery and styling that reflects the city's culture
- **Smooth Animations**: Engaging scroll animations and hover effects
- **Interactive Elements**: Menu filtering, image galleries, and form interactions

### Sections
1. **Hero Section**: Eye-catching introduction with call-to-action buttons
2. **About Section**: Restaurant story and key features
3. **Menu Section**: Interactive menu with category filtering
4. **Gallery**: Beautiful food and restaurant images
5. **Contact Section**: Location details and table booking form
6. **Footer**: Social links, quick navigation, and newsletter signup

### Technical Features
- **Mobile-First Design**: Optimized for mobile devices
- **Smooth Scrolling**: Enhanced navigation experience
- **Form Validation**: Contact and newsletter forms with validation
- **Image Modal**: Click to enlarge gallery images
- **Back to Top Button**: Easy navigation to the top of the page

## 🛠️ Customization

### Adding Menu Items
To add new menu items, edit the `index.html` file and add new `.menu-item` elements in the menu section:

```html
<div class="menu-item" data-category="category-name">
    <img src="image-url" alt="Dish Name">
    <div class="menu-item-content">
        <h3>Dish Name</h3>
        <p>Description</p>
        <span class="price">₹Price</span>
    </div>
</div>
```

### Changing Colors
Modify the CSS variables in `styles.css` to change the color scheme:

```css
:root {
    --primary-color: #ff6b35;
    --secondary-color: #f7931e;
    --dark-color: #2c1810;
}
```

### Adding New Sections
To add new sections, follow the existing pattern in `index.html` and add corresponding styles in `styles.css`.
